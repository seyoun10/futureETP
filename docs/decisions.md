## D-001: 화면 구조 재정의 (원자재 목록 + 원자재 화면 탭 4개)
- 날짜: 2026-10-22
- 상태: 확정
- 맥락: 초안은 홈 한 화면에서 원자재를 칩으로 전환하고 탭 4개(혼합 차트/커브/이격도/ETP)를 두었다. Step 1 역검증에서 사용자가 화면 구조를 새로 정의했고, 인베스팅·트레이딩뷰·증권사 MTS·가상자산 앱의 차트 화면과 비교해 세부를 다듬었다.
- 선택지: (1) 초안 유지 (2) 홈 = 원자재 목록, 원자재 화면 = title-bar + tab-bar 4개
- 결정: (2). 세부 내용은 `wireframes/screens.md`가 기준이다.
  - 홈(A)은 원자재별 만기순 연속 5개 월물 시세 목록
  - 원자재 화면(C) 탭: 이격도차트(C-a) / 월물커브(C-b) / 월물차트(C-c) / ETP 목록(C-d)
  - 혼합 차트 제거. 기준값 지수는 C-a 일봉 봉차트로 보여 준다.
  - 이격도는 별도 % 차트 대신 가격 차트 위 rare-level 밴드(이평선 × (1 + 레벨 이격도))로 보여 준다.
  - 커브는 실제 월물 x축, 기준일(D-1 기본, −/0/+ 이동) 대비 비교. 롤 수익률 요약은 유지한다.
  - 기간 버튼 10종 + 핀치·드래그, C-a~C-c 가로 전환, 다크 전용, 등락 색 설정(기본 한국식)
- 근거:
  - 원자재 4종의 월물 시세를 한눈에 보는 목록이 진입점으로 더 유용하다.
  - 혼합 차트의 지수 흐름은 C-a 봉차트와 겹친다.
  - 가격 위 밴드는 "현재 가격이 얼마나 드문가"를 가격 단위로 바로 보여 주고, 유사 서비스의 익숙한 차트 형태와 맞는다.
  - 기준일 대비 커브는 하루 동안의 커브 변화를 직관적으로 보여 준다.
